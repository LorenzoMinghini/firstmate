herdr agent-name cap BEFORE creating any endpoint. Reproduces the live
failure from 2026-09-15 (40-char id 'm5-audit-chain-test-double-contamination'
where herdr silently rejected an over-cap name while the wrapper reported
success and stranded the replacement endpoint).

Test setup: FM_GATE_REFUSE_BYPASS=1 so the gate-refuse guard (which
refuses all fleet ops from inside a no-mistakes gate worktree) does not
fire. The cap check fires BEFORE any fleet mutation, so this bypass
only affects the test harness, not the cap guard under test.
